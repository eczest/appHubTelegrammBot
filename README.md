# AppHub Telegram Bot

Служебный Telegram-бот управляет меню канала AppHub: публикует и обновляет пост с
фотографией и URL-кнопками, показывает приватный предпросмотр, хранит список менеджеров и
умеет автоматически публиковать меню по расписанию.

## Настройка

Нужен Python 3.12. Создайте `.env` из примера и заполните значения:

```dotenv
BOT_TOKEN=токен_из_BotFather
MANAGER_CHAT_ID=-1000000000000
CHANNEL_ID=-1001693528783
CHANNEL_URL=https://t.me/apphub_store
ADMIN_USER_IDS=998527660
TIMEZONE=Asia/Yekaterinburg
LOG_LEVEL=INFO
```

`ADMIN_USER_IDS` содержит владельцев бота через запятую. Владельцы не могут быть удалены
через Telegram и только они могут назначать дополнительных менеджеров.

Бот должен быть администратором канала с правами публикации и редактирования сообщений.
Закрепление сообщений бот не выполняет.

## Команды

Все административные команды выполняются в личном чате с ботом.

- `/start` или `/info` — инструкция.
- `/test` — точный предпросмотр меню в личном чате без отправки в канал.
- `/publish_menu` — публикация нового меню в канале.
- `/update_menu` — обновление последнего опубликованного меню.
- `/menu_status` — состояние меню, последняя публикация и таймер.
- `/buttons` — добавление, удаление и изменение порядка URL-кнопок.
- `/managers` — добавление и удаление менеджеров; только для владельца.
- `/timer` — выбор интервала кнопками.
- `/timer 30m`, `/timer 6h`, `/timer 1d` — произвольный интервал от 5 минут до 30 дней.
- `/timer off` — отключение автоматической публикации.
- `/chatid` — Telegram ID текущего чата или пользователя.

Рекомендуемый порядок: изменить кнопки через `/buttons`, проверить `/test`, затем выполнить
`/update_menu`. Если меню еще не публиковалось или старый пост удален, используйте
`/publish_menu`.

Автопубликация создает новый пост меню при каждом срабатывании. Новый пост становится
последним управляемым сообщением для `/update_menu`.

## Хранение данных

Базовое меню находится в `config/channel_menu.yaml`. После первого изменения через
`/buttons` рабочая копия сохраняется в `data/channel_menu_runtime.json`.

В `data` также сохраняются:

- `channel_menu_state.json` — ID последней публикации;
- `admin_users.json` — дополнительные менеджеры;
- `menu_timer.json` — расписание автопубликации.

Runtime-файлы не добавляются в Git. В Docker папка `/app/data` размещается в именованном
volume `apphub_data`, поэтому данные переживают пересборку контейнера.

## Локальный запуск

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m app.main
```

Тесты:

```bash
source .venv/bin/activate
pytest
```

## Docker

Запуск:

```bash
docker compose up -d --build
```

Логи:

```bash
docker compose logs -f bot
```

Обновление после `git pull`:

```bash
docker compose up -d --build
```

Остановка:

```bash
docker compose down
```

Команда `docker compose down -v` удаляет сохраненные кнопки, менеджеров, таймер и состояние
последней публикации. Без `-v` данные сохраняются.

Бот использует long polling, поэтому открывать входящие сетевые порты для него не нужно.
