# Изображения

Бот умеет отправлять локальные изображения, если соответствующий файл существует. Если файла нет, бот запишет предупреждение в лог и отправит только текст с кнопками.

Предусмотренные пути:

- `assets/channel_menu.jpg` - картинка для Rich Message меню канала.
- `assets/categories/catalog.png` - приветственная картинка и общая картинка для списка категорий.
- `assets/categories/contacts.png` - картинка для раздела контактов.
- `assets/categories/iphone.png` - картинка категории iPhone.
- `assets/categories/macbook.png` - картинка категории MacBook.
- `assets/categories/other.png` - общая заглушка для остальных категорий.

Поддерживаемые форматы зависят от Telegram. Сейчас проект настроен на добавленные `.png`-файлы.

Рекомендуемый размер: 1200x800 px или близкий к нему горизонтальный кадр. Файлы можно заменить без изменения Python-кода, если путь в `config/catalog.yaml` не меняется.
